# Imágenes de productos

Coloca aquí las fotos de cada producto (por ejemplo `panales-plenitud-protect-xg.jpg`, `keppra-100mg.jpg`, `avena-puritas.jpg`) y referencia la ruta en la propiedad `imagen` de cada ítem dentro de `necesidadesVenela` en `index.html`.

Ejemplo:
```js
{ id: 1, producto: "Pañales Plenitud Protect XG 32 unidades", ..., imagen: "assets/img/productos/panales-plenitud-protect-xg.jpg" }
```

Si `imagen` queda vacío (`""`), la tarjeta muestra automáticamente un ícono identificador de la categoría correspondiente.
